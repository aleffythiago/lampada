# Minha primeira página web 💡

Este é meu primeiro projeto desenvolvido com HTML, CSS e JavaScript.

Uma página simples e interativa, onde é possível clicar em um botão para ligar e desligar uma lâmpada.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Localize o arquivo `index.html`.
3. Abra o arquivo em um navegador.
4. Clique no botão para testar a interação com a lâmpada.

Não é necessário instalar programas ou dependências adicionais.
